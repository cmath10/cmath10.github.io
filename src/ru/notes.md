# Заметки

Эта страница может вырасти в короткие эссе, инженерные заметки или даже в небольшие changelog-подобные обновления.

## Перспективные форматы заметок

- уроки из поддержки Vue-библиотек
- мысли о форме API и качестве документации
- заметки про автоматизацию релизов
- эксперименты с remote rendering и composition boundaries
- размышления о design tokens, theming и выборе component systems

## Редакторская идея

Лучше делать записи короткими и регулярными, чем ждать, пока накопится материал на большой и идеально отполированный пост.
